Gestión de Datos de Países en Python

Descripción del Programa

El programa permite gestionar información geográfica de distintos países almacenada en un archivo CSV. A través de un menú interactivo, el usuario puede agregar países, actualizar información, realizar búsquedas, aplicar filtros, ordenar registros y obtener estadísticas.

Instrucciones de Uso

1. Descargar o clonar el repositorio.

2. Verificar que el archivo "Información Geografica.csv" se encuentre en la misma carpeta que el programa.

3. Ejecutar el archivo principal.

4. Seleccionar una opción del menú e ingresar los datos solicitados.

Funcionalidades

* Agregar países.
* Actualizar población y superficie.
* Buscar países.
* Filtrar por continente.
* Filtrar por rango de población.
* Filtrar por rango de superficie.
* Ordenar por nombre.
* Ordenar por población.
* Ordenar por superficie.
* Mostrar estadísticas.
